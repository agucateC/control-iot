Acerca de

Aplicación de Control (Etapa 1): envía comandos a la API REST y escucha eventos por WebSocket.

  • WSS: sesión WebSocket real del navegador.
  • AWS: la API responde a /salud.
  • RDS: solo con el diagnóstico /salud/rds; si no existe, «Sin verificar».

Ninguno confirma que el vehículo físico esté en línea, ni que ejecutó un movimiento: «Aceptado por la API» y «Evento WSS» solo prueban el mensaje.

Teclado: flechas/WASD mueven el joystick; Esc detiene.
